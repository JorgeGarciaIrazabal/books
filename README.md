# Book Studio

Write and revise books, essays, and illustrated stories with an AI writing
studio. Open this workspace in your writing app and ask for what you want
in ordinary language.

| Ask the studio | What you'll get |
| --- | --- |
| “Help me start a mystery for young readers.” | A premise, a short plan, and a first sample. |
| “Continue where I left off.” | The next step from the latest available work and notes. |
| “Tell me where the opening loses momentum.” | Specific reader feedback and a revision to try. |
| “Show me a reading copy with the pictures in place.” | A checked copy you can open and read. |
| “Let me hear a warmer narrator.” | A short audio sample you can listen to. |
| “Save my progress.” | A saved version, shared automatically where the studio has access and permission. |
| “Publish this edition to the library.” | The live edition and a link for readers. |

You make the creative and publication decisions. The studio handles routine
saving, file preparation, and checks. The public library is for editions you've
chosen to release. Open the [Book Studio catalog](https://jorgegarciairazabal.github.io/books/).
