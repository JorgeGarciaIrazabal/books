# Editorial reviews

Each report names reviewer/session/model, role, date, exact input snapshot, paths,
coverage/omissions, findings, and limitations. A report is not complete because a
file exists. Keep first judgments independent from the drafter's defense.

Issue records need stable IDs, location, severity, error/risk/taste category,
evidence, reader impact, suggested intervention, disposition, and recheck evidence.
Use blocker/major/minor/note; resolve with a check or record an accepted exception.
Checkpoints need pass/revise/not-applicable, snapshot, reviewer, report, and reason.
Changed inputs require rechecking affected reviews. Inspect the assembled export.
