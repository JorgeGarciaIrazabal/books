# Reading edition

Required output: a fifty-page 7 x 10 inch PDF, one title page, forty-eight story pages, and one optional read-together page. Twelve chapters of four pages; word count must be recorded from actual text. Supply assembled Markdown for editing. Type is at least 13 points; layout must fail on overflow rather than silently crop or shrink text. Page illustrations are simple original vector drawings made in code, not sourced art. No invented author byline or endorsements. No claim of publication readiness. No external material or attributed quotations are planned.

Build with production/build.py using Python and reportlab. Install dependencies in an isolated environment. Final proof must inspect page count, text presence, overflow, extraction, chapter order, and rendered representative pages. Actual editorial review and visual checks must be described in the handoff. Author retains publication decisions; no upload or publication is part of this assignment.

Additional author request: supply a format suited to Android phones and tablets. Build a reflowable EPUB 3 from the same ordered manuscript, with reader-controlled font sizing, linked chapter contents, and the same optional questions. PDF page breaks must not constrain the EPUB; its page count varies by display and settings. Preserve manuscript and existing PDF. Validate the actual EPUB package with EPUBCheck and complete-text comparisons. Provide local file and Google Play Books import instructions; do not upload it to an account. No physical-device rendering claim without an actual test.
