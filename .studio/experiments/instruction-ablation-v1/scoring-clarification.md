# Scoring clarification before any peer review
The protocol’s reviewer-dependence guard is operationalized as follows: if removing any one reviewer model changes either fixture’s updated preference from above half to half or below, keep the current live contract rather than apply the whole proposed block. A tie is not evidence of improvement.

Objective violations include incompatible timing/capacity/custody/knowledge assertions, unsafe unqualified repair alternatives, seeded-line misses, definite false positives and inaccurate explicit rule locators. Query-only ambiguities and optional style choices are kept separate. Diagnosis and repair are checked manually after mechanical line matching; a correct error line alone does not establish a sound repair. A wrong locator is recorded separately from an error-detection miss.

This clarifies broad protocol language after some candidate outputs were read, but before any blind peer ranking was collected. It is a conservative adoption rule and not a claim of fully preregistered statistical analysis. Treatments, tasks and fixtures are unchanged.
