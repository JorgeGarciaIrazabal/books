# Writing model pilot v1
Preregistered 2026-10-24 before collecting candidate outputs. Scope: eight phases on one original speculative civic mystery; one completion per supported condition. A bundled response contains eight independent tasks; this is a screening pilot, not evidence of whole-book performance or cross-genre superiority. Shared fixed fixtures prevent earlier outputs from changing later assignments. Bundle order and runtime/system-prompt differences remain confounds.

Requested: Kimi K3, GPT-6.1 Sol, GPT-6 Sol, Mistral Large V4, each medium/high. Actual effort controls must be supported; never rename an effort or infer it from a prompt. Record omitted conditions and any author-approved substitutions. Preserve model route, effort, runtime, source hashes, wall time when measurable, raw output, and failures. Price/token claims only when supplied by the runtime; otherwise unavailable. No silent retries to select a better sample.

Peer ranking: fresh sessions, identity-blind packets, randomized candidate order with saved seed, exact same-model outputs excluded at BOTH efforts. Each reviewer ranks every included candidate separately for each phase, permits ties, and cites concrete passages/decisions for strongest and weakest choices. Judge using task fidelity, causal/technical correctness, specificity, usable craft, and voice preservation as appropriate; no fabricated numerical literary scores. The director retains dissent and checks factual/continuity findings against a sealed key. Model judgments are preferences, not representative reader research.

Aggregation: derive pairwise preferences from rank tiers. Compare candidates only among judges eligible to see both; average medium/high judgments within each reviewer model first, then weight reviewer models equally. Ties contribute half. Report equal-opponent average preference, sample counts, per-reviewer rankings, disagreements, and whether removing a reviewer changes the recommendation. These are preference frequencies, not quality scores. Do not pool phase ranks into a universal model champion. Model families here mean exact model IDs; the two Sol versions share a provider and may share biases. Report this limitation.

A same-model effort comparison can use the other model reviewers only. A phase recommendation is provisional; call inconclusive when evidence is split or sparse. No significance claims with one sample. A second independent fixture/genre and author blind reading are needed before changing permanent studio model defaults. Research, factual accuracy on external sources, long context, whole-book editing, production proof, and art are not assessed.

Mechanical checks: packet/source hashes; required phase sections; word counts as diagnostics; all ranks cover eligible IDs exactly once; quoted evidence exists; continuity errors audited against key. Mechanical checks do not assess literary quality.
